Вам надано робочий приклад (див. код з уроку), який уже містить:
* PWM керування двигуном (LEDC)
* Зчитування енкодера через PCNT (quadrature x4)
* Обробку кнопки BOOT (GPIO0)
* Базову реалізацію PID-регулятора
* Логування в консоль

Ваше завдання — не писати все з нуля, а зрозуміти та модифікувати цей код.

Стенд складається з:
* ESP32-S3
* Двигун постійного струму
* NPN-транзистор (керування PWM)
* Енкодер (модуль KY-040 з EC11 механічним енкодером)
* Вали двигуна та енкодера з’єднані жорстко

Результат

При натисканні кнопки BOOT0:
* збільшується цільове положення (setpoint)
* двигун має повернутись на 90° або 180° (на вибір студента)
* система повинна:
    * досягати заданого кута
    * стабільно зупинятись
    * не мати значних коливань
* Необхідно підібрати:
    * PID_KP
    * PID_KI
    * PID_KD

Методи:
* Зіглер–Ніколсон
* ручний підбір (експериментально)
